Desafío Técnico

Desarrollar una simulación móvil con rendimiento sostenido a 60 FPS en gráficos 3D que permita interactuar con física de fluidos/partículas y agitación de objetos en tiempo real.

Solución Implementada

Se crearon Custom Shaders en Shader Graph dentro de URP (Universal Render Pipeline) junto con scripts C# modulados que gestionan la instanciación eficiente de prefabs usando Object Pooling.

Tecnologías Clave

Unity, C#, Universal Render Pipeline, Shader Graph, VFX Graph, Input System.
